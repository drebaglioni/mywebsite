# Artegna photograph

`artegna.webp` is a resized WebP conversion of **33011 Artegna UD, Italy - panoramio.jpg**, photographed by **iw3rua**, 5 January 2009.

Source: https://commons.wikimedia.org/wiki/File:33011_Artegna_UD,_Italy_-_panoramio.jpg

The other photographs are the site's existing `home-merthyr.jpg`, `home-princeton.jpg`, and `home-sanfrancisco.jpg` assets. The page applies SVG color mapping without altering their architecture or geography.
